Change Log & Future Updates

LAST UPDATED: OCTOBER 20, 2026

October 20, 2026 Release

Current Version

Prefix commands have been removed and automatic host link detection is no longer supported. The Bot may allow authorized users to export and import operational Bot data. Server administrators and moderators should regularly use /data export and /data import as a best practice to back up runtime data in case the Bot is updated, restarted, or redeployed.

  • Architecture & Prefix Removal: Completely removed all legacy prefix commands (p. commands) and automatic message-parsing features across the entire bot codebase and documentation. Disabled automatic chat-based Forest link detection to prevent inaccurate timers and reliance on Message Content Intent restrictions.
  • Host & Image Enhancements: Enhanced /plant image so users can save a default host image that automatically applies whenever they host a session, complete with an image preview feature. Added the admin-level /assign plant image command to assign default host images for other users. Refined image override logic: specifying an explicit image_url parameter in /host overrides the user's saved default image, while omitting images entirely prevents broken embeds.
  • Stats & Leaderboard Redesign: Redesigned plant stats embeds to feature the user's avatar as a thumbnail and display their saved plant image as the main banner embed. Maintained compact, paginated layouts for stats and leaderboards to ensure stability within Discord embed size limits. Integrated history modifications allowing moderators to edit or delete existing finished logs via /assign plant modify.
  • Data Management Updates: Updated /data summary, /data export, and /data import commands to provide public responses instead of ephemeral ones, including full preservation of user image preferences.
  • Help & Documentation Overhaul: Updated the public /help panels and comprehensive guide manuals to reflect exclusive slash-command usage, removing all references to prefix commands or text-matching workflows. Completely rewrote and updated the Privacy Policy and Terms of Service drafts.

April 26, 2025 Release

  • Added /plant image for saving default host images.
  • Added /assign plant image allowing admins to assign default host images for other users.
  • Added /assign plant modify allowing moderators to edit or delete existing finished plant logs.
  • Added p.lb as a new prefix alias for p.leaderboard.
  • Improved timer and host synchronization so p.edit and /plant edit update original host embeds when the session came from a tracked host post.
  • Updated duration validation limits: minimum plant duration is 10 minutes and maximum is 180 minutes across timers, host flows, request durations, assigned timers, and stats.
  • Updated /status no-active footer to suggest /plant start and /host.
  • Plant image preferences are now fully included in /data summary, /data export, and /data import.

Future Roadmap & Planned Features

  • Auto-assign image URLs that apply automatically on every host command with image preview verification.
  • Dedicated HTML website enhancements for advanced community documentation hosting.

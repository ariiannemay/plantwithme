PlantWithMe Bot Complete Guide

LAST UPDATED: OCTOBER 20, 2026

Prefix commands have been removed and automatic host link detection is no longer supported[cite: 1]. The Bot may allow authorized users to export and import operational Bot data[cite: 1]. Server administrators and moderators should regularly use /data export and /data import as a best practice to back up runtime data in case the Bot is updated, restarted, or redeployed[cite: 1].
1. Setup Checklist & Bot Role Permissions

Setup Checklist:

  1. Invite the bot with Bot and applications.commands scopes[cite: 4].
  2. Give the bot a server role with the core, mention, cleanup, and voice permissions listed below[cite: 4, 5].
  3. Make sure the bot can see and send messages in the channels where you want to use it[cite: 4].
  4. If you want voice support, allow the bot to view and connect to voice channels[cite: 4, 5].
  5. If you want role pings, make sure the bot role is allowed to mention roles and sits high enough in the role list[cite: 4, 5].
  6. Restart the bot after changing intents in the Developer Portal[cite: 4].

Recommended Permissions:

  • Recommended Core Permissions: View Channels, Send Messages, Embed Links, Attach Files, Read Message History[cite: 5].
  • Recommended Mention Permissions: Mention @everyone, @here, and All Roles[cite: 5].
  • Recommended Cleanup Permissions: Manage Messages (useful for removing prompt messages and temporary launchers)[cite: 5].
  • Voice Permissions: View Voice Channels, Connect (needed for /join, /leave, /vctime)[cite: 5].
2. Global Rules and Limits

Duration Limits: Minimum plant duration is 10 minutes; maximum is 180 minutes[cite: 6]. Applies to plant timers, hosted sessions, assigned timers, stats durations, and requests[cite: 6].

Stats & Leaderboard Recording: Only naturally finished timers count toward finished-session history[cite: 6]. Stopped, deleted, or reset timers do not count[cite: 6].

Server Scope: Plant status selection is server-scoped[cite: 6]. Timers from another server will not appear in the current server's status selection logic[cite: 6].

Help Visibility: Public help intentionally hides mod/admin/owner tools[cite: 6, 14].

3. Accepted Input Formats
  • User Inputs: Accepts @mention, raw Discord user ID, username, or display name[cite: 7].
  • Leaderboard Modes: host or tree[cite: 7]
  • Timeframes: all, today, week, month[cite: 7]
  • Date Formats For Finished Stats Editing: 2026-04-26 18:30, 04/26/2026 18:30, or April 26, 2026 6:30 PM[cite: 7]
  • Comma-Separated Assign Inputs: For assignment commands, subscriber and target_user fields accept comma-separated lists[cite: 7].

5. Troubleshooting & FAQ

User lookup problems: If username lookup fails, ensure Server Members Intent is enabled in the Developer Portal and restart[cite: 15].

Host embed did not update after edit: Very old host posts created before host-message tracking was added cannot be retroactively linked[cite: 15].

Why did data disappear after restart? In-memory runtime state disappears on restart unless administrators regularly use /data export and /data import[cite: 15, 16].

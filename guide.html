PlantWithMe Bot Complete Guide

LAST UPDATED: OCTOBER 20, 2026

Prefix commands have been removed and automatic host link detection is no longer supported. The Bot may allow authorized users to export and import operational Bot data. Server administrators and moderators should regularly use /data export and /data import as a best practice to back up runtime data in case the Bot is updated, restarted, or redeployed.
1. Setup Checklist & Bot Role Permissions

Setup Checklist:

  1. Invite the bot with Bot and applications.commands scopes.
  2. Give the bot a server role with the core, mention, cleanup, and voice permissions listed below.
  3. Make sure the bot can see and send messages in the channels where you want to use it.
  4. If you want voice support, allow the bot to view and connect to voice channels.
  5. If you want role pings, make sure the bot role is allowed to mention roles and sits high enough in the role list.
  6. Restart the bot after changing intents in the Developer Portal.

Recommended Permissions:

  • Recommended Core Permissions: View Channels, Send Messages, Embed Links, Attach Files, Read Message History.
  • Recommended Mention Permissions: Mention @everyone, @here, and All Roles.
  • Recommended Cleanup Permissions: Manage Messages (useful for removing prompt messages and temporary launchers).
  • Voice Permissions: View Voice Channels, Connect (needed for /join, /leave, /vctime).
2. Global Rules and Limits

Duration Limits: Minimum plant duration is 10 minutes; maximum is 180 minutes. Applies to plant timers, hosted sessions, assigned timers, stats durations, and requests.

Stats & Leaderboard Recording: Only naturally finished timers count toward finished-session history. Stopped, deleted, or reset timers do not count.

Server Scope: Plant status selection is server-scoped. Timers from another server will not appear in the current server's status selection logic.

Help Visibility: Public help intentionally hides mod/admin/owner tools.

3. Accepted Input Formats
  • User Inputs: Accepts @mention, raw Discord user ID, username, or display name.
  • Leaderboard Modes: host or tree
  • Timeframes: all, today, week, month
  • Date Formats For Finished Stats Editing: 2026-04-26 18:30, 04/26/2026 18:30, or April 26, 2026 6:30 PM
  • Comma-Separated Assign Inputs: For assignment commands, subscriber and target_user fields accept comma-separated lists.
4. Complete Slash Command Reference
Core & Hosting
  • /version — Running version timestamp
  • /help — Paginated help panel
  • /host — Primary hosting command
  • /trees — Paginated tree list
  • /show_tree — Selected tree image
  • /random_tree — Random tree image
  • /join, /leave, /vctime — Voice controls
Plant & Subscriptions
  • /plant start — Create timer (10-180m)
  • /plant edit — Edit active timer
  • /plant stop — Stop active timer
  • /plant status — View active timers
  • /plant image — Set default host image
  • /plant leaderboard — View leaderboards
  • /plant stats — Inspect summary stats
  • /plant subscribe / unsubscribe
Admin & Moderator Assign & Data Tools
  • /assign plant request — Admin create request
  • /assign plant timer — Admin create active timer
  • /assign plant stats — Mod add finished plant log
  • /assign plant modify — Mod edit or delete logs
  • /assign plant image — Admin set default image for user
  • /assign plant subscription — Mod manage relationships
  • /data summary, export, import — Admin backup tools
5. Troubleshooting & FAQ

User lookup problems: If username lookup fails, ensure Server Members Intent is enabled in the Developer Portal and restart.

Host embed did not update after edit: Very old host posts created before host-message tracking was added cannot be retroactively linked.

Why did data disappear after restart? In-memory runtime state disappears on restart unless administrators regularly use /data export and /data import.

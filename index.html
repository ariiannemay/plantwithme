Slash Command Reference

The bot operates exclusively via clean Discord slash commands and interactive modals.

Core & Hosting Commands

  • /host — Primary command to start a guided Forest hosting session with room codes and banners.
  • /trees & /show_tree — Browse available tree species and view artwork.
  • /version — Shows current bot version timestamp.
  • /help — Displays the interactive paginated help panel.

Plant & Timer Controls

  • /plant start mins: tree: — Create a 10–180 minute focus timer.
  • /plant edit — Edit your latest active or pending timer.
  • /plant stop — Stop an active timer (stopped timers do not count toward stats).
  • /plant status — View active timers for yourself or other members.

Community & Tracking

  • /plant leaderboard — View paginated host or tree leaderboards.
  • /plant stats — Inspect summary stats and recent completed sessions.
  • /plant subscribe — Subscribe to host pings for specific users.
  • /plant request add — Request specific trees and durations.

Moderator & Admin Tools

  • /assign plant stats — Add a finished session log for any user.
  • /assign plant modify — Edit or delete existing session logs.
  • /data export / import — Backup or restore runtime JSON data.
  • /plant reset — Reset finished-session statistics by scope.

Quick Setup Checklist

Get PlantWithMe up and running in your Discord server in under 2 minutes.

1

Invite the Bot

Invite the bot with Bot and applications.commands scopes.

2

Configure Role Permissions

Ensure the bot role has View Channels, Send Messages, Embed Links, Read Message History, and Mention Roles permission.

3

Enable Gateway Intents

Enable Server Members and Message Content intents in the Discord Developer Portal, then restart the bot.

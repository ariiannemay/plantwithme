Bot's General Information & Purpose

The PlantWithMe Bot is designed to make Forest App sessions easier to share, manage, and track inside Discord communities. It helps users host focus sessions, invite others to join, keep track of active plant timers, and view finished-session stats and leaderboards. Its main purpose is to make Forest-based coworking and productivity sessions feel more natural inside Discord, especially in study, focus, accountability, and wellness communities.

Why was the bot created? (Click to expand)

The bot was created to bridge the gap between Forest App and Discord. Without the bot, sharing Forest sessions manually can be repetitive and messy. Users often need to copy session details, explain start times, send room codes, and reformat everything themselves. The PlantWithMe Bot automates that process by turning Forest session data into clear Discord embeds and timer tools.

This makes it easier to:

  • host Forest sessions
  • invite others to join
  • track active plants
  • get notified when specific users host
  • request specific trees or durations
  • view long-term planting stats and leaderboards

The goal is to make collaborative focus sessions smoother, more organized, and more engaging.

Forest Session Hosting (/host)

Users can manually run /host and provide their Forest session details using interactive parameters. Automatically formats session duration, tree name, start/end times, room codes, optional remarks, and interactive join buttons.

Plant Timers (/plant)

Track Forest timers directly. Manually start (10 to 180 mins), edit active or pending timers, stop timers, or check server status for yourself and other members.

Stats & Leaderboards

Track completed sessions with /plant stats and /plant leaderboard across all, today, week, and month timeframes for hosts and tree types.

Requests & Subscriptions

Request specific trees/durations to trigger automatic pings, or subscribe to specific hosts so you get notified instantly whenever they host a new session.

Full Owner & User Reference Manual

PlantWithMe Bot Complete Guide

LAST UPDATED: OCTOBER 20, 2026

1. Setup Checklist & Bot Role Permissions

Setup Steps:

  1. Invite the bot with Bot and applications.commands scopes.
  2. Give the bot a server role with the permissions listed below.
  3. Make sure the bot can see and send messages in channels where you want to use it.
  4. If you want voice support, allow the bot to view and connect to voice channels.
  5. If you want role pings, make sure the bot role is allowed to mention roles and sits high enough in the role list.
  6. Restart the bot after changing intents in the Developer Portal.

Recommended Permissions:

  • Core: View Channels, Send Messages, Embed Links, Attach Files, Read Message History
  • Mentions: Mention @everyone, @here, and All Roles
  • Cleanup: Manage Messages
  • Voice: View Voice Channels, Connect
2. Global Rules and Limits

Duration Limits: Minimum plant duration is 10 minutes; maximum is 180 minutes.

Stats & Leaderboard Recording: Only naturally finished timers count toward finished-session history.

Server Scope: Plant status selection is server-scoped.

Help Visibility: Public help intentionally hides mod/admin/owner tools.

3. Accepted Input Formats
  • User Inputs: Accept @mention, raw user IDs, usernames, or display names.
  • Leaderboard Modes: host or tree
  • Timeframes: all, today, week, month
  • Date Formats: 2026-04-26 18:30, 04/26/2026 18:30, or April 26, 2026 6:30 PM
4. Complete Slash Command Reference
Core Commands
  • /version — Shows running version timestamp
  • /help — Paginated help panel
  • /host — Primary hosting interface
  • /trees — Paginated tree list
  • /show_tree — View selected tree image
  • /random_tree — Random tree image
Plant Commands
  • /plant start — Manual timer
  • /plant edit — Edit active timer
  • /plant stop — Stop active timer
  • /plant status — View timer status
  • /plant image — Set default host image
  • /plant leaderboard — Host/tree ranks
  • /plant stats — View user statistics
  • /plant subscribe / unsubscribe
Admin & Moderator Assign Commands
  • /assign plant request — Admin create request
  • /assign plant timer — Admin create active timer
  • /assign plant stats — Mod add finished plant log
  • /assign plant modify — Mod edit/delete logs
  • /assign plant image — Admin set default image for user
  • /assign plant subscription — Mod manage subscriptions
  • /data summary, export, import — Admin data backups
5. Troubleshooting & FAQ

User lookup problems: Ensure Server Members Intent is enabled in the Developer Portal and restart.

Host embed did not update after edit: Very old host posts created before message tracking cannot be linked.

Why did data disappear after restart? In-memory state clears unless administrators use /data export and /data import.

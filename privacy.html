Data Practices & User Privacy

Privacy Policy

Effective Date: April 26, 2026 | LAST UPDATED: OCTOBER 20, 2026

Prefix commands have been removed and automatic host link detection is no longer supported. The Bot may allow authorized users to export and import operational Bot data. Server administrators and moderators should regularly use /data export and /data import as a best practice to back up runtime data in case the Bot is updated, restarted, or redeployed.

PlantWithMe Bot ("the Bot") respects user privacy and aims to collect and retain only the information needed to provide its features inside Discord. This Privacy Policy explains what information the Bot processes, why it is processed, how long it may be retained, and what rights users and server administrators have.

1. Information the Bot Processes

The Bot may process and store the following categories of information when used in Discord:

  • Discord IDs and Server Context: Discord user IDs, server IDs, channel IDs, message IDs, and role IDs where applicable for server-specific ping behavior.
  • User-Provided Command Data: Selected tree names, timer durations, elapsed time or start timing data, plant requests, subscription relationships, assigned plant images, optional host remarks, optional image URLs, and user-provided dates for moderator-added or modified stats entries.
  • Forest Session Data: Room code, join link token or link, tree name, session duration, and host timing information.
  • Finished Session History: User ID, server ID, tree name, duration, and completed timestamp used for stats and leaderboards.

2. How the Information Is Used

The Bot uses this information only to operate its Discord features, including creating and managing plant timers, generating host-session embeds, sending subscription and request pings, tracking finished plant sessions, showing stats and leaderboards, and exporting and importing Bot data. The Bot does not use this information for advertising or profiling.

3. Data Storage and Retention

Unlike a purely ephemeral bot, PlantWithMe Bot uses persistent storage for operational Bot data (active plant timers, tree requests, subscription records, completed session history, saved plant image preferences, and host-session metadata). Data remains stored until manually removed, overwritten by imported backups, or cleared by the Bot's reset logic.

4. Data Export, Import, and Sharing

Server administrators may use Bot data-management commands to export and import Bot data. The Bot does not sell user data and does not intentionally share stored Bot data with third parties for commercial purposes, though hosting providers technically process data as part of normal infrastructure operation.

5. User Choices and Rights

Users may request that certain stored data be corrected or removed where applicable (such as removing a subscription, removing a plant request, or requesting correction/deletion of a manually assigned finished-session log) by contacting server staff or the developer.

6. Security

Reasonable efforts are made to limit stored data to operational Bot needs. However, no method of electronic storage or transmission is completely secure, and server administrators should handle exported Bot data files carefully.
